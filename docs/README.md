# Tài liệu dự án

Lưu tài liệu được cả nhóm thống nhất tại đây, ví dụ: yêu cầu chức năng, sơ đồ dữ liệu, hợp đồng API và hướng dẫn kiểm thử. Chưa có tài liệu phân chia nhiệm vụ chi tiết được chốt.

- [Hướng dẫn làm việc Frontend](FRONTEND_GUIDE.md): vị trí đặt code, quy tắc đặt tên và cách dựng giao diện bằng dữ liệu mẫu.
